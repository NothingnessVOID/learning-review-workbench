# v1.1 网页验收记录

2026-09-24，以真实 Google Chrome 无头浏览器运行 `npm run test:e2e`。测试启动随机端口的临时 DEMO 服务，结束后关闭服务并删除测试库；不在正式库写入。两套脚本顺序通过，输出见 `artifacts/test-results/ui-v1.1.txt`。

`ui-test.mjs` 覆盖课程→主题→原文、来源前后文、阅读位置、断网保留输入与幂等重试、记录反馈与复盘归档、归档恢复、关联审核、草稿差异、导出及文本导入。

`ui-regression.mjs` 增加以下复现回归：

- 导出范围、分享选项或脱敏词改变后旧预览失效；过时响应不能生成错误下载。
- 快速记录、反馈和复盘的保存期间继续输入，旧响应不清除新文字；离开再返回仍保留草稿。
- 短主题和长主题的续读位置、离开前保存；打开记录时按当前主题关联，连续两条记录保留关联。
- 160 条同词记录的列表与搜索分页、同日起止日期筛选、设置权限及导出较早记录，并核对服务端参数。
- 外部复盘交接只包含明确选定记录，来源需另选；能力缺口可见。
- 对话框键盘焦点循环、Escape、关闭后焦点回到触发按钮；移动菜单关闭后侧栏不可聚焦；辅助文字计算对比度达到 4.5。

三个宽度均无页面横向溢出。CI 使用 Playwright 托管 Chromium，本机可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定浏览器。失败时保存截图和 trace，CI 始终收集回归证据。trace 为测试产物，不提交源码仓库。

本报告不等于真实课程语义质量验收或用户本人 T30 验收。超过 30 门课程/知识卡的视觉路径和独立屏幕阅读器尚未单独测试。
