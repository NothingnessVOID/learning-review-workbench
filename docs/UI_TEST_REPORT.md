# 网页验收记录

2026-09-24 在隔离演示服务 `http://127.0.0.1:47832` 上，以 Google Chrome 153.0.8010.53 的无头模式运行真实浏览器操作。演示数据目录为 `.data/demo`。正式服务 `47831` 仅检查了空库首页，没有写入测试记录。

复跑命令：`node scripts/ui-test.mjs`。脚本启动时检查侧栏的“独立演示资料”标识，并拒绝写入 `47831`。每次运行会在演示库增加一条带时间戳的 UI 验收记录及后续反馈，也会确认一份固定名称的 TXT 演示来源；重复导入由服务端按来源去重。

已通过的浏览器操作：课程列表进入课程、主题讲义、固定来源原文；在原文中展开前文和后文；滚动阅读后离开并重新进入，位置恢复；主题中自动关联“记一句”；模拟 `/api/rpc` 网络失败后，文字与 `client_request_id` 保存在 `localStorage`，刷新页面后以同一请求 ID 重试，记录列表只出现一次；在原始记录后追加反馈和保存外部复盘；归档记录后用“含已归档”找回并恢复；审阅并确认一条演示关联；打开草稿的可读差异；勾选个人记录并生成导出预览及下载链接；TXT 导入预览后确认。

前端 `npm run typecheck` 和 `npx vite build` 已通过。此报告只覆盖演示库里的网页操作。备份恢复的数据库一致性、MCP 客户端协议调用及真实资料质量另由对应后端测试与人工验收记录说明。
