## 导入实现

Markdown、TXT、JSON 与 ZIP 具备预览、暂存、映射、提交和清理流程。资料包的临时来源 ID、区段 ID 和主题 ID 可按清单路径、内容身份或区段顺序建立映射；预览显示可解释的匹配计划。来源字节单独写入受控 staging，SQLite 仅保存预览元数据与校验摘要；取消、成功、失败和过期会清理暂存。实施细节见 `DATA_SCHEMA.md`。

通用 JSON schema 支持不表示任意旧资料包都兼容。遇到未知字段或无法唯一映射时应停止并修复清单，不猜测内容，也不跳过错误。
