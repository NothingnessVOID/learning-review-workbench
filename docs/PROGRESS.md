# 交接与进度

当前第二轮复审版本为 1.2.0，基准为 109a904。修复聚焦续读真正落库、本地日历筛选、完整正文比较、确认关联的一致性，以及复盘交接与快速记录。逐项结论和复跑命令见 `SECOND_REVIEW.md`，实际日志见 `artifacts/test-results/second-*`。

## 工程验收

工程流程由临时 SQLite 库、真实浏览器及官方 SDK 自动执行，不要求用户代替开发人员验收保存、筛选、关联或交接。固定旧提交运行附件五项模板全部失败；修复后使用真实的新日期和比较合同继续验证原断言。

当前实现保留单主库、不可变来源、个人层隔离、草稿人工采用、保存期间新输入保护、导出过时结果失效、损坏恢复与分页。MCP 现有 23 项工具，新增两项只读详情，不扩大写权限。

## 数据边界

正式库不写入合成测试记录，也不自动采用真实草稿。公开仓库仅含软件、通用说明、合成夹具、截图及日志；私人上下文、来源、备份和真实样本验证留在本机忽略目录。

已在授权本地目录找到实际课程资料包，当前做只读盘点与有界隔离样本验证。通用 Markdown 导入不能自动识别整包课程、观点卡和案例卡语义，实际整包的分类、回链和字段映射不能由合成包测试替代。详细范围以第二轮记录为准。

## 后续只保留真实判断

用户主观体验、课程语义忠实度与完整方法 Skill 的执行效果仍需实际使用判断。软件工程路径的验证责任由开发测试承担。完整包批量入库、远程部署、手机连接本机、云同步和跨 schema 自动迁移没有在本轮交付中声称完成。

恢复工作时先读 `AGENTS.md`、`SECOND_REVIEW.md`、`DATA_SCHEMA.md`、`API_CONTRACT.md` 和 `TEST_REPORT.md`。开发用 `npm run build`、`npm test`，真实数据不得作为回归测试库。
