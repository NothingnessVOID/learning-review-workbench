## 工程验收

工程流程由临时 SQLite 库、真实浏览器及官方 SDK 自动执行，不要求用户代替开发人员验收保存、筛选、关联或交接。固定旧提交运行附件五项模板全部失败；修复后使用真实的新日期和比较合同继续验证原断言。

当前实现保留单主库、不可变来源、个人层隔离、草稿人工采用、保存期间新输入保护、导出过时结果失效、损坏恢复与分页。MCP 现有 23 项工具，新增两项只读详情，不扩大写权限。

## 数据边界

正式库不写入合成测试记录，也不自动采用真实草稿。公开仓库仅含软件、通用说明、合成夹具、截图及日志；私人上下文、来源、备份和真实样本验证留在本机忽略目录。

已在授权本地目录找到实际课程资料包，当前做只读盘点与有界隔离样本验证。通用 Markdown 导入不能自动识别整包课程、观点卡和案例卡语义，实际整包的分类、回链和字段映射不能由合成包测试替代。详细范围以第二轮记录为准。
