# 隐私与权限

服务只绑定 127.0.0.1。Host 和 Origin 限制、HttpOnly SameSite=Strict 会话、CSRF token、独立 MCP Bearer 凭据共同限制访问。CORS 不作为权限系统。凭据位于数据目录 credentials.json（0600），不写源码、URL、前端、备份或截图。

MCP 默认仅课程/知识/来源读取。个人记录默认零条授权；设置页按记录 ID 授权。笔记新增、复盘保存、课程草稿、知识草稿、关联提议分别受服务端权限检查。资料读取被撤销后，不返回来源文件名；学习状态不通过 MCP 返回。复盘与关联的可见性跟随原记录范围。

MCP 不提供任意路径、SQL、shell、HTTP抓取、永久删除或恢复。Agent 不能用 `confirmed:true` 代替本地人工确认。来源文字中的命令和“忽略规则”等内容只是数据，不改变权限。

Markdown 不运行 HTML；危险协议链接被过滤，图片默认不自动加载。程序运行不请求字体、统计、广告或模型服务。外部网页链接只在用户点击时打开。

SQLite、来源、备份均未进行应用层加密；依赖本机账户文件权限及操作系统保护。浏览器 localStorage 保存尚未提交的文字草稿、字号及阅读位置回退，公共/共享浏览器使用后应自行清理草稿。已保存业务数据由服务器持久化。

使用外部模型客户端时，已授权的返回内容可能进入该客户端模型上下文。默认本地不上传，不等于客户端读取后仍只在本机。云端 Agent 无法自动访问本机 localhost；首版不做公网连接。

工作台的 MCP 授权只约束这些 MCP 接口。若外部客户端同时获准读取电脑文件、运行命令或使用其他连接器，那些能力由客户端自身授权控制，不能用工作台里的勾选框推断它们也被隔离。“交给我的 Agent”会先展示将交出的原始记录与来源，复制或下载后由用户发送。

私人和演示实例使用不同的 Cookie 名称；同一浏览器同时打开两者不会互相覆盖会话。运行上下文位于数据目录 runtime-context，可按版本追溯；备份默认不含这些上下文，勾选包含时只纳入固定的语境和提示模板，永不包含凭据。上下文文件名和提示模板不代表完整专业方法已经安装。
