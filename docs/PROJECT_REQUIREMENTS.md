# 可分享的软件需求

交付本地运行的中文学习网页、SQLite 持久化、来源快照、真实官方 SDK stdio MCP 和备份恢复。

核心闭环：导入原始资料 → 课程地图与主题讲义草稿 → 引用原文 → 人工采用 → 知识卡跨课关联 → 随手记与独立复盘 → 续读和检索。

验收重点：

- 三入口：课程、知识、我的记录；浅色阅读、键盘可用、390/768/1280px适配。
- SourceDocument / SourceVersion / SourceBlock / Course / Topic / KnowledgeCard / Case / Note / ReviewResult / Relation / LearningState / Draft / Revision / Audit 语义分离。
- 原文快照不可变，来源定位真实，不补不存在的页码/时间戳。
- Markdown/TXT/JSON/ZIP先预览，哈希去重、同名版本保留、ZIP路径与体积限制。
- 中文短词、专名、明确别名及繁简检索；命中片段来自原文。
- 个人输入、学习状态与阅读位置不被资料更新覆盖；保存失败保留草稿，重试幂等。
- MCP 官方协议握手与真实调用，权限由服务端校验，正式采用/恢复只允许本地网页。
- 全库或选定范围导出；课程导出不夹笔记；备份一致性快照和隔离恢复校验。
- 不做网页内置聊天模型、云同步、公网部署、自动转写、自动抽牌、医学诊断或打卡排名。

用户原始长规格、私人语境、真实素材清单和衍生讲义均留在本机忽略路径，不是仓库内容。审查入口见 REVIEW_GUIDE.md。
